GIT LÀ GÌ? CÁC LỆNH CƠ BẢN CỦA GIT

Các lệnh git cơ bản

  1. git config

    Tác dụng: Để set user name và email của bạn trong main configaration file.

    Cách dùng: Để kiểm tra tên và kiểu email trong cấu hình dùng

    git config--global user.name git config--global user.email

    Để set email hoặc tên mới

    git config --global user.name ="Hải Nguyễn" git config--global user.email="hainguyen@gmail.com"
  2. git init

    Tác dụng: Khởi tạo 1 git repository 1 project mới hoặc đã có.

    Cách dùng: git init trong thư mục gốc của dự án.

  3. git clone

    Tác dụng: Copy 1 git repository từ remote source.

    Cách dùng: git clone <:clone git url:>

  4. git status

    Tác dụng: Để check trạng thái của những file bạn đã thay đổi trong thư mục làm việc. Ví dụ: Tất cả các thay đổi cuối cùng từ lần commit cuối cùng.

    Cách dùng: git status trong thư mục làm việc.

  5. git add

    Tác dụng: Thêm thay đổi đến stage/index trong thư mục làm việc.

    Cách dùng: git add

  6. git commit

    Tác dụng: commit nghĩa là một action để Git lưu lại một snapshot của các sự thay đổi trong thư mục làm việc. Và các tập tin, thư mục được thay đổi đã phải nằm trong Staging Area. Mỗi lần commit nó sẽ được lưu lại lịch sử chỉnh sửa của code kèm theo tên và địa chỉ email của người commit. Ngoài ra trong Git bạn cũng có thể khôi phục lại tập tin trong lịch sử commit của nó để chia cho một branch khác, vì vậy bạn sẽ dễ dàng khôi phục lại các thay đổi trước đó.

    Cách dùng: git commit -m "Đây là massage, bạn dùng để note những thay đổi để sau này dễ dò lại"

  7. git push/ git pull

    Tác dụng: Push hoặc Pull các thay đổi đến remote. Nếu bạn đã added và commit các thay đổi và bạn muốn đẩy nó lên hoặc remote của bạn đã update và bạn apply tất cả các thay đổi đó trên code của mình.

  8. git remote

    Tác dụng: Để check remote/source bạn có hoặc add thêm remote Cách dùng: git remote để kiểm tra và liệt kê. Và git remote add <:remote_url:> để thêm.

  9. git add

    Tác dụng: Để đưa một tập tin vào Staging Area.

    Cách dùng: git add tên_file hoặc muốn thêm hêt file của thư mục thì git add all
